# نوا (Nava)

سرویس استریم موسیقی — پروژه‌ی درس برنامه‌سازی وب، دانشگاه صنعتی شریف.

- `frontend/` — Next.js 16 + React 19 + TypeScript + Tailwind
- `backend/` — Django 5.2 + Django REST Framework + JWT

---

## راه اول: داکر (ساده‌ترین راه)

اگر فقط می‌خواهید پروژه را **ببینید و تست کنید**، همین یک دستور کافی است:

```bash
docker compose up --build
```

سپس مرورگر را روی **<http://localhost:3000>** باز کنید.

پایگاه داده، بک‌اند و فرانت‌اند با هم بالا می‌آیند و **داده‌های نمایشی خودکار ساخته
می‌شوند** — نیازی به هیچ کار دیگری نیست.

اگر پورتی روی سیستم شما اشغال بود:

```bash
BACKEND_PORT=8010 FRONTEND_PORT=3010 docker compose up --build
```

برای خاموش کردن: `Ctrl+C` و سپس `docker compose down`.

## راه دوم: اجرای دستی (برای توسعه)

به **دو ترمینال** نیاز دارید. بک‌اند روی پورت **۸۰۰۱** و فرانت‌اند روی **۳۰۰۰**.

> پورت ۸۰۰۱ اختیاری نیست: آدرس `http://localhost:8001/api` در فایل
> `frontend/.env.local` نوشته شده و فرانت‌اند از همان‌جا API را صدا می‌زند.

### ترمینال ۱ — بک‌اند

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed          # ساخت داده‌های نمایشی (فقط بار اول)
python manage.py runserver 8001
```

### ترمینال ۲ — فرانت‌اند

```bash
cd frontend
npm install
cp .env.example .env.local     # آدرس API (فقط بار اول)
npm run dev                    # http://localhost:3000
```

## نکته‌های مهم

**زبان.** رابط کاربری فارسی (RTL) و انگلیسی (LTR) را پشتیبانی می‌کند؛ از
«تنظیمات ← زبان» عوض می‌شود. نام آهنگ‌ها، آلبوم‌ها و هنرمندان **ترجمه نمی‌شوند** —
این‌ها داده‌اند، نه متن رابط کاربری (مثل خود اسپاتیفای).

**PWA.** سرویس‌ورکر فقط در حالت تولیدی فعال است، نه در `npm run dev`:

```bash
cd frontend && npm run build && npm start
```

بعد از آن اپلیکیشن قابل نصب است و آفلاین هم بالا می‌آید.

**پرداخت.** به‌صورت پیش‌فرض از **سندباکس زرین‌پال** استفاده می‌شود که به هیچ
حساب پذیرنده‌ای نیاز ندارد. اگر سندباکس در دسترس نبود، این خط را در
`backend/.env` بگذارید تا همان مسیر پرداخت به‌صورت آفلاین اجرا شود:

```
PAYMENT_GATEWAY=fake
```

## اگر به مشکل خوردید

**خطای «ارتباط با سرور برقرار نشد»** — بک‌اند بالا نیست، یا شما روی پورت اشتباهی
هستید. مطمئن شوید فرانت‌اند روی **۳۰۰۰** و بک‌اند روی **۸۰۰۱** است:

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:8001/api/subscriptions/plans/
```

اگر `401` برگشت یعنی بک‌اند سالم است (احراز هویت لازم دارد). اگر `000` برگشت،
بک‌اند اجرا نشده است.

**پورت اشغال است** — ببینید چه چیزی روی آن پورت است و ببندیدش:

```bash
lsof -ti:8001 | xargs kill
```

**صفحه‌ی قدیمی نشان می‌دهد** — اگر قبلاً بیلد تولیدی را اجرا کرده‌اید،
سرویس‌ورکر ممکن است نسخه‌ی کش‌شده را نشان دهد. در DevTools از بخش
Application ← Storage گزینه‌ی Clear site data را بزنید.

**خطای عجیب در بیلد** — هیچ‌وقت `npm run build` را هم‌زمان با `npm run dev`
اجرا نکنید؛ هر دو از پوشه‌ی `.next` استفاده می‌کنند. اول `dev` را ببندید:

```bash
cd frontend && rm -rf .next && npm run build
```
